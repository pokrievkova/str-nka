# Elegance Nails

Responzívna úvodná stránka nechtového štúdia vytvorená v čistom HTML, CSS a JavaScripte. Na zobrazenie stránky nie je potrebné nič inštalovať; otvorte `index.html` v prehliadači alebo použite VS Code Live Preview.

## Súbory

| Súbor | Obsah |
| --- | --- |
| `index.html` | Sekcie stránky, služby a rezervačný formulár |
| `styles.css` | Vizuálny štýl a responzívne rozloženie |
| `script.js` | Mobilná navigácia a ukážkové potvrdenie formulára |
| `img/` | Obrázky použité na stránke |
| `docs/style-guide.md` | Farebná paleta, typografia a dizajnové odporúčania |

## Pred zverejnením

Konkrétne služby, ceny, kontaktné údaje, otváracie hodiny, recenzie a fotografie treba potvrdiť a doplniť podľa údajov štúdia. Rezervačný formulár je zatiaľ iba ukážka v prehliadači: údaje sa neodosielajú ani neukladajú a vybraný termín sa nepotvrdzuje. Na prijímanie skutočných rezervácií je potrebné prepojiť ho s rezervačným systémom alebo backendom.
